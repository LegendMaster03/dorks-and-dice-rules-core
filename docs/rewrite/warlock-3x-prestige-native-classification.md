# Warlock 3.5e prestige material — case-by-case native classification

**Status:** preliminary compatibility classification study only (2026-10-24); no owner-approved disposition for these four features/classes and no authorization to integrate non-SRD content into the current Warlock vertical slice.

## Governing distinction

Rules Core deliberately treats imported **source** `prestigeClass` and `subclass` as different identities and preserves their original advancement and prerequisite metadata. That is *source fidelity*, **not an instruction to keep the same effective category in Dorks & Dice native design**. The native category is determined case by case using the established classification approach. If a native specialization replaces or represents a prestige class, retain explicit provenance/version correspondence and do not silently relabel the imported original.

The proposed Warlock specialized development model should convert eligible historical mechanics **directly into coherent native parts or a guided preset**, without forcing 3.5e options through a fictitious modern 5e Patron subclass. A true prestige/hybrid advancement track remains supported when it better preserves the material.

## Practical evaluation questions (research lens, not a newly adopted mandatory scoring rule)

1. **Class dependence:** Does the specialization mainly extend Warlock-specific capabilities, such as Eldritch Blast, invocations and Pact effects, or does it represent a separate profession/open cross-class career?
2. **Entry requirements:** Do requirements simply establish meaningful competency within Warlock, or is prior advancement in another class essential?
3. **Progression ownership:** Can its milestones be represented as Warlock class-level-eligible parts or bundles, or must it advance one or more independent class-level tracks?
4. **Resource and effect relationships:** Can its powers use shared effects, existing pools, prerequisites, and upgrades without duplicating base-class grants? Are trade-offs or sacrifices fundamental to its identity?
5. **Faithful preset/complexity:** Can guided play reconstruct the original theme and core trade-offs while advanced play chooses eligible parts? Does decomposing it actually benefit players, or just recreate a rigid prestige class in disguise?
6. **Edition reconciliation:** Can the same native parts coexist with 2014/2024 Warlock rules under approved native effect and source-mapping policies? Never conflate matching names with matching mechanics, or class-specialization themes with Patron identity.

**Existing native constraints:** Do not reintroduce historical alignment restrictions as binding class access rules. Preserve distinct character/class level tracks and native rest/competency policies. No free ability duplication or automatic cross-class entitlement.

## Four historical cases

| 3.5e source prestige class | Original mechanical identity | Tentative native candidate | Main unresolved conversion issue |
| --- | --- | --- | --- |
| **Hellfire Warlock** (*Fiendish Codex II*, 3 levels) | Warlock-only specialization requiring a specific Blast Essence invocation; strengthens Eldritch Blast with dangerous hellfire, includes a bodily cost, plus infusion/defense improvements; progresses invocation-using class | **Warlock specialization parts + a Hellfire guided path** | Preserve the meaningful cost/trade-off and unusual source prerequisite without requiring the non-SRD option in the initial SRD-only slice; avoid simply making an arbitrary bonus-damage invocation |
| **Enlightened Spirit** (*Complete Mage*, 10 levels) | Warlock-like transformation toward celestial/spiritual powers with Spirit Blast, auras, flight, defenses, and its own Eldritch Blast gains | **Warlock thematic advancement branch or cohesive bundle/preset** | Original has a long, tightly connected progression that should not be flattened into free-floating abilities; no automatic equivalence to a modern **Celestial Patron** |
| **Eldritch Disciple** (*Complete Mage*, 10 levels) | Requires *divine spellcasting*, invocations and turn/rebuke capacity; chiefly progresses invocation use plus a separate divine spellcasting class | **Likely retains prestige/hybrid dual-track advancement** | Maintaining actual divine spell progress alongside Warlock invocations; a Warlock-only preset must not manufacture divine progression without prerequisite entitlements |
| **Eldritch Theurge** (*Complete Mage*, 10 levels) | Requires *arcane spellcasting* and invocations; jointly progresses existing arcane casting and invocation-using class | **Likely retains prestige/hybrid dual-track advancement** | Faithful dual-track scaling, multiclass prerequisites, and ability-budget equivalence; a purely Warlock specialization would erase its cross-class role |

The tentative candidates are **not approvals**. A source prestige class with a short 3.5e level table is not inherently required to keep a separate table, and a source prestige class with a long table is not automatically a native subclass. It depends on the actual class relationships and gameplay costs.

## Why this matters to the active vertical slice

- The approved implementation remains **SRD 5.1 + SRD 5.2.1** full Band 1 Warlock including Fiend, Pacts and invocations, plus prior approved historical 3.5e *base-class* feature rulings.
- The four non-SRD 3.5e prestige classes are **reference-only compatibility stress cases**, useful for verifying the model is not incompatible with future thematic paths or multiclass progression.
- Do **not** add Hellfire or Enlightened Spirit playable features, 3.5e heritage feat catalogs, or 3.5e invocation prerequisites to the active content inventory now.
- Once the SRD-based Warlock model is tested, revisit each historical prestige's **effective native category** individually. A Warlock-exclusive source class may become a native part tree and preset, while another can properly remain a prestige/hybrid with its own progression.
