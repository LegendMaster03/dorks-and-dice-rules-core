# Selected structured book rules and tables

The first batch projects nine SRD 5.1 tables, fifteen SRD 5.2.1 tables and one multiclassing rule per edition from the pinned book JSON. The selections and page locators are explicit in `tools/promote_srd_book_rules.mjs`. These are native, edition-local definitions; whole book chapters are not promoted. The source's top-level occurrence remains the inventory key and the exact nested `entryPointer` identifies the material used. One linked occurrence does not certify its whole chapter.

Preserve original column ordering and row representations, including grouped headers, fractions, dice expressions and the distinction between the legacy travel effects table and modern distance table. The selected tables cover advancement, proficiency, ability scores, multiclassing, travel, coins and modern encounter budgets. The existing glossary, item and deity catalogs are not duplicated. The legacy multiclass prerequisites and proficiency tables are linked to the applicable local classes; modern prerequisites and proficiencies remain in the class descriptions. The publisher prints different half-caster rounding in the two editions (5.1 p.58 down, 5.2.1 p.25 up). Both source book JSONs include extra Eldritch Knight/Arcane Trickster contributions absent from the official passages; remove them. Nested multiclass tables are represented by canonical table references, not copied data. No executable advancement or spell-slot mechanics are added.

The generator validates each selected node's identity, row count, column width, publisher heading, unique identity and local reference targets. CI compares exact generated output. Table layout and selected rule text were reviewed; comprehensive cell-by-cell comparison, remaining general rule sections, navigation tag classification, class spell-list reconciliation and other semantic fidelity remain open.
