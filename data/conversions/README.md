# Source conversions

Reserved for versioned, reviewed, deterministic mappings from third-party or older-edition source data into the Dorks & Dice native ontology. Clear mappings may be automatic; ambiguous conversions remain unresolved for review.

Preserve original source identity, exact revisions, fingerprints and license/provenance independently of converted native mechanics. Do not automatically treat an import as permission to publish restricted text.

## Skills import-name mapping

`skill-name-mappings.json` is **future-import conversion evidence**, not a native Skill definition or an executable importer. It recognizes reviewed previous-edition skill names and maps them to native skill IDs. No import step is needed to read native `skills.json`.
