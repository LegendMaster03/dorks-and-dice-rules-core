# Native skill data

The 18 foundational 5e-family skills are directly maintained as **one native JSON entity per skill**, not loaded from a third-party source database. Each includes a default Ability and draft summaries/details curated from corresponding SRD-marked 5etools records.

The two text fields are **provisional source-based descriptions** requiring mechanical reconciliation. The final engine uses the approved Dorks & Dice native rules here. This folder is separate from the wider universal `competencies/` taxonomy, which links a skill where appropriate.
