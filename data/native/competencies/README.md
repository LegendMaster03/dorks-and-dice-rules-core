# Universal Dorks & Dice competencies

A competency is an independently identified, universal learned capability. Some competencies reference a native skill through `nativeSkill`; others preserve ranked 3.x granular state, Craft/Perform/Profession organization or tool facets.

Review and preserve distinctions documented in `main:docs/universal-character-concepts.md`: semantic aliases are not automatic numeric equivalences; composite parent values derive one-way from individually tracked components; and skill versus tool profiles may use one training identity but independent numeric mechanics.

The current files are a **starter catalog**, not the complete vetted competency roster and not an implemented gameplay evaluator. Add each remaining reviewed family member, standalone tool and rules profile in later slices.
