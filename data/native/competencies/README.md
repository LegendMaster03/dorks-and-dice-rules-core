# Universal native competencies

Reserved for one primary JSON document per independent Dorks & Dice semantic competency, with explicit identities, aliases, family/parent relations, source-specific mechanical facets, provenance and conditional composition. Do not flatten all source skills and tool proficiencies into one numeric implementation.

Reviewed baseline behavior is documented in `docs/universal-character-concepts.md` (historical reference), and the staged test vectors in `data/reference/competency-reconciliation-cases.json`. Exact schema and native mechanics are not implemented yet.
