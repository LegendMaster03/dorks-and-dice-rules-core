# Class taxonomy

Base classes (`base/`), subclasses (`subclasses/<parent-class>/`), prestige classes (`prestige/`), NPC classes (`npc/`), and sidekick classes (`sidekick/`) are separate native categories.

Subclasses use a parent-class relationship and share that class's advancement; prestige classes retain independent advancement and prerequisites. Epic/Level Band continuations are part of their owning class document, not independent progression entities. Explicit stable IDs and relationships, not path parsing, govern runtime behavior.
