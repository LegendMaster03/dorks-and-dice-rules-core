# Biological origination characteristics

This directory groups the canonical **Species and Ancestry origin-trait definitions**
used in biological Origination. The `traits/` subfolders preserve the former
Species-family and shared-definition organization.

The move from `native/traits/` is a **content-only relocation**. Every
`trait.*` ID, JSON definition, `traitId` reference, mechanical field and
source-occurrence index remains unchanged. This is not a new gene rules
category or inheritance mechanism.

A trait located here is **not** automatically biologically transmissible.
Eligibility continues to follow the authored biological transmission contract
and explicit trait permissions. Canonical IDs are source-neutral and may be
referenced by other authorized origination methods; the directory is only a
storage grouping.

`NativeCatalogLoader` discovers these definitions recursively. Research
tools must read this location. Commit-pinned historical links to the former
directory remain valid for their original revisions.
