# Real SRD import pilot fixture

`real-srd-actions-pilot.json` is a deliberately small real-data fixture containing the `Attack` action records for `SRD51` and `SRD52` from the SRD-only 5e.tools-shaped data pack maintained at `CoolFireGiant/hewnhero-srd` (`data/actions.json`, source blob `bfad297daac1319c51d27fe8fa106161fa78222a`).

The fixture is used only to stress the Rules Core import/version-detection path with actual SRD-shaped content. It is intentionally limited to two records rather than vendoring the broader corpus.

The underlying System Reference Document 5.1 and System Reference Document 5.2.1 material is published by Wizards of the Coast LLC under the Creative Commons Attribution 4.0 International license (CC BY 4.0). The `hewnhero-srd` repository likewise identifies its SRD-only data as CC BY 4.0.
